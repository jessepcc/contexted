# Posture: maximum discovery for the public marketing surface (/, /about, /blog),
# nothing for the private funnel. Search engines, AI answer engines, and training
# crawlers are all allowed to read the public pages.

# Every agent gets its own group with its own Disallow lines rather than inheriting
# from "*". That is deliberate: a crawler obeys only the most specific group that
# names it and does NOT merge in the wildcard group's rules, so omitting the
# Disallow lines here would expose the app funnel to every bot named below.
#
# Cloudflare serves a managed robots.txt (which disallows the training crawlers) to
# sites that ship none of their own. This file replaces it — if it is removed, the
# training bots get blocked again by default.
